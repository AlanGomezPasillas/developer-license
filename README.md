# 🪪 Developer License - An Interactive Credential

Static web application written in *HTML5* and *CSS3* to showcase your
skills, links, and everything you can imagine. The technologies
used in this project make it optimal, responsive, clean, and
lightweight. It's also *free* and *open-source*.

🔗 **Demo:** [developer-license.alangomezpasillas.workers.dev](https://developer-license.alangomezpasillas.workers.dev/)

## Details

It's simple but powerful. This is the first version of the project;
it uses best practices for SEO and accessibility. It's great if you
just want a fast and lightweight way to share your links, skills,
and experience. 

Right now it's pure HTML and CSS, so you have to edit everything
manually, but the plan is to make a **C++ generator** where you just
enter your information and it generates your credential just like
that, easy and fast! 

In addition, I'm planning to add more sections:
- **Experience:** Share school or working backgrounds.
- **Technical Stack:** Programming languages, tools, operating systems,
  and certifications (maybe linking languages and tools with them?).

I hope you like it. I'm going to use it.
